# ChronosTerrae 🌍⏳

[🇪🇸 Leer en Español](#-chronosterrae-en-español)

**ChronosTerrae** is a scientific knowledge infrastructure and a deep-time cartographic rendering engine. Its goal is to map the topological, geopolitical, ecological, and cultural evolution of the Earth from the formation of Pangaea to the present, utilizing a decentralized validation model.

## Project Architecture

The system does not rely on a static human database. It is designed to operate under an asynchronous architecture:

1. **AI Harvester Swarm:** Distributed Artificial Intelligence nodes will extract, compile, and cross-reference data from open-source historical repositories.
2. **CRDT System & Collision Resolution:** Massive simultaneous integration without server collapse.
3. **Academic Consensus (Proof of Authority):** Every temporal polygon and historical event injected by the algorithmic swarm goes through a strict layered human validation flow (Tiers), requiring verifiable sources (DOIs, archaeological records).

## WebGL Web Engine

The visual client uses **MapLibre GL JS**, isolating modern border layers from the base map to exclusively render historical vector polygons that visually mutate according to the temporal threshold (Papyrus Era vs. Paper/Modern Era).

## Funding & Scalability

ChronosTerrae is an open-source project built on a *guerrilla* architecture. It currently operates on zero-cost static servers. 

The storage of future massive vector tiles (PMTiles) and the AI validations will require external infrastructure and dedicated domains (.org).

## 🇪🇸 ChronosTerrae (Español)

**ChronosTerrae** es una infraestructura de conocimiento científico y un motor de renderizado cartográfico de tiempo profundo. Su objetivo es mapear la evolución topológica, geopolítica, ecológica y cultural de la Tierra desde la formación de Pangea hasta el presente, utilizando un modelo de validación descentralizado.

## Arquitectura del Proyecto

El sistema no depende de una base de datos estática humana. Está diseñado para ser operado bajo una arquitectura asíncrona:

1. **Enjambre Recolector IA:** Nodos distribuidos de Inteligencia Artificial extraerán, compilarán y cruzarán datos de repositorios históricos de código abierto.
2. **Sistema CRDT y Resolución de Colisiones:** Integración masiva simultánea sin colapso del servidor.
3. **Consenso Académico (Prueba de Autoridad):** Cada polígono temporal y evento histórico inyectado por el enjambre algorítmico pasa por un flujo estricto de validación humana por capas (Tiers), requiriendo fuentes verificables (DOI, registros arqueológicos).

## Motor Web WebGL

El cliente visual utiliza **MapLibre GL JS**, aislando las capas de fronteras modernas del mapa base para renderizar exclusivamente polígonos vectoriales históricos que mutan visualmente según el umbral temporal (Era de Papiro vs Era de Papel/Moderna).
